# SlimanKhan GitHub Profile — setup

## Install

1. Open https://github.com/SlimanKhan.
2. Open the profile repository named **SlimanKhan**.
3. Upload/replace `README.md`.
4. Upload the complete `assets/` folder, preserving its folder structure.
5. Upload `scripts/generate_stats.py` and `.github/workflows/refresh-stats.yml`, preserving their paths.
6. Commit the changes.

Use **Add file → Upload files**. Drag the files/folders from the extracted ZIP into the upload area. If folder upload is unavailable, create the folders in GitHub and upload each file to its matching path.

## Enable automatic statistics

Open the repository's **Actions** tab, enable workflows if prompted, then run **Refresh profile statistics** once using **Run workflow**. It will also refresh weekly.

The workflow reads public GitHub profile/repository data. No personal access token is normally required.
